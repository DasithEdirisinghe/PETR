# PETR: localization by apparent object size within class

Apparent size is `sqrt(projected GT width × projected GT height)` in the camera with the largest clipped GT box area. GT objects are divided into equal-count small, medium, and large groups **separately for each class and 5 m GT-range bin**. This compares sizes at approximately the same distance. 35 GT objects outside all camera images are omitted from the size analysis.

Retention uses only the original 4 m true positives; coverage uses all GT in the group. These are not AP values. The heatmap greys out comparisons with fewer than 30 original 4 m TPs in either tertile.
