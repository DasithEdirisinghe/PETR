# PETR radial, tangential, and full-center oracle

Run from the PETR repository root in the cluster `petr` environment:

```bash
python experiments/nuscnes_exp/localization_oracle/run_oracle.py
```

The script uses the baseline formatted validation predictions and `data/nuscenes` by default. It fixes same-class, confidence-ordered nuScenes matches at center distance `<4 m`, corrects only global XY for those predictions, and runs the official nuScenes detection evaluator on the baseline and three corrected submissions. It writes `outputs/baseline/summary.md`, `ap_comparison.csv`, and each variant's `metrics_summary.json` and `results_nusc.json`.

Each oracle is an upper-bound diagnostic for the original 4 m matched subset. Official evaluation performs new matching after correction; predictions without an original 4 m match remain unchanged.

To plot **baseline PETR** GT coverage by class, GT ego range, and the four
center-distance thresholds, after running the GT-coverage experiment:

```bash
python3 experiments/nuscnes_exp/localization_oracle/summarize_baseline_range.py
```

This writes `outputs/baseline/classwise_summary.md` and
`baseline_gt_coverage_by_class.svg`. The percentages use all eligible GT as
their denominator and are distinct from AP. The classwise **correction-oracle
AP** report is separately generated by
`python3 experiments/nuscnes_exp/localization_oracle/summarize_classwise.py`
as `outputs/baseline/oracle_classwise_summary.md`.
