# Baseline PETR: classwise GT coverage by ego range

![GT coverage by class, range, and center-distance threshold](baseline_gt_coverage_by_class.svg)

The percentages below use **all evaluator-eligible GT in the class and range bin** as the denominator. Each threshold uses independent, same-class confidence-ordered matching. The `All` row pools all GT for that class across ranges. These are GT coverage rates, **not AP**; AP also uses confidence ranking and false positives.

The same-run baseline official AP is **5.08% @0.5 m**, **21.92% @1 m**, **45.06% @2 m**, and **59.07% @4 m**; overall mAP is **32.78%**. These AP figures should not be read as GT coverage percentages.
